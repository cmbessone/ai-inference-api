## Nivel 1 — Contexto

¿Quién usa el sistema y con qué sistemas externos habla?

```mermaid
C4Context
    title AI Inference API — Contexto

    Person(dev, "Cliente de la plataforma", "Backend o app de un cliente SaaS que integra IA")
    Person(ops, "SRE / Operaciones", "Monitorea SLOs y despliega")

    System(api, "AI Inference API", "Inferencia LLM (sync + SSE) y clasificación con modelo propio. Rate limit, cache y resiliencia.")

    System_Ext(llm, "Proveedor LLM", "OpenAI u otro (mock por defecto)")
    System_Ext(obs, "Observabilidad", "Prometheus + recolector de logs")

    Rel(dev, api, "POST /v1/infer, /v1/infer/stream, /v1/classify", "HTTPS + X-API-Key")
    Rel(api, llm, "Completions / streaming", "HTTPS, keep-alive")
    Rel(ops, obs, "Consulta dashboards y alertas")
    Rel(obs, api, "Scrapea /metrics, lee logs JSON")
```

## Diagramas dinámicos

### `POST /v1/infer` con thundering herd (Escenario A)

```mermaid
sequenceDiagram
    autonumber
    participant C1 as Cliente 1..N
    participant R as Réplica
    participant SF as SingleFlight (local)
    participant RD as Redis
    participant L as LLM

    C1->>R: POST /v1/infer (X-API-Key)
    R->>RD: EVALSHA sliding_log(client_id)
    RD-->>R: permitido, remaining=59
    R->>RD: GET cache:infer:v1:<sha256>
    RD-->>R: nil (miss)
    R->>SF: do(key)
    Note over SF: requests 2..N de esta réplica<br/>esperan la misma tarea
    SF->>RD: SET key:lock token NX PX
    alt soy líder
        RD-->>SF: OK
        SF->>RD: GET key (double-check)
        SF->>L: complete() [breaker → bulkhead → timeout]
        L-->>SF: completion
        SF->>RD: SET key value PX ttl
        SF->>RD: EVAL compare-and-delete lock
    else otra réplica es líder
        RD-->>SF: nil
        loop backoff 20 ms → 250 ms
            SF->>RD: GET key / GET key:failed
        end
    end
    SF-->>R: resultado compartido
    R-->>C1: 200 {request_id, output, usage, latency_ms, cache_hit}
```

### `POST /v1/infer/stream` con backpressure y desconexión (Escenario C)

```mermaid
sequenceDiagram
    autonumber
    participant C as Cliente
    participant G as Generador SSE
    participant Q as Queue(maxsize=64)
    participant P as Productora
    participant L as LLM
    participant A as AuditSink

    C->>G: POST /v1/infer/stream
    G->>P: create_task(produce)
    P->>L: stream (breaker admit)
    loop por token
        L-->>P: token
        P->>Q: put() — bloquea si está llena (backpressure)
        Q-->>G: get()
        G-->>C: data: {"token", "index"}
    end
    alt cliente se desconecta
        C--xG: disconnect
        G->>P: cancel()
        P->>L: aclose() → cierra conexión upstream
    else cola llena > 10 s (slow consumer)
        P->>Q: drenar + {"error": "slow_consumer"}
        P->>L: aclose()
    else fin normal
        P->>Q: data: [DONE]
    end
    P->>A: submit(record) — no bloqueante
```

### Estados del circuit breaker (Escenario B)

```mermaid
stateDiagram-v2
    [*] --> Closed
    Closed --> Closed: éxito / fallo (< 5 en 30 s)
    Closed --> Open: 5.º fallo en 30 s
    Open --> Open: request → 503 llm_unavailable (retry_after_s)
    Open --> HalfOpen: pasaron 60 s
    HalfOpen --> Closed: probe OK
    HalfOpen --> Open: probe falla
    HalfOpen --> HalfOpen: otros requests → 503 (un solo probe en el clúster)
```
